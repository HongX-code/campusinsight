# 演示视频脚本（高校智讯 CampusInsight）

> 目标时长 **5 分 30 秒**（初赛材料，非答辩）。
> 录制方式：1920×1080，浏览器缩放 100%，关闭无关标签页与书签栏。
> 解说与画面必须对应实际系统，不描述尚未实现的功能。
> 本轮按 **Arctic Glass 学生端闭环**重排分镜，界面口径见 `docs/ui_design.md`。

---

## 拍摄前准备

| 项目 | 要求 |
| --- | --- |
| 环境 | 本地 `python run.py --open` 后访问 `http://127.0.0.1:8000/`，或云端 Demo 地址，二者选一，全片不混用；**不要用 `0.0.0.0` 当网址** |
| 数据 | 先执行 `python scripts/reset_db.py`，保证 66 条演示通知（24 构造样本 + 42 真实采集）、3 个演示用户 |
| 账号 | 使用者「李思远」（大三 / 信息管理与信息系统），兴趣填「学科竞赛、奖学金」 |
| 浏览器 | 一个窗口、一个标签页；1920×1080 主视口；另备 **390×844 移动端视口**（展示固定 5 项底部导航，可画中画或切一次） |
| 录制 | OBS 或系统自带录屏，1080p 30fps，麦克风单独录后再对轨 |

**开场前先把三件事做掉**（否则录制中断会很难看）：

1. 先跑 `python run.py --check` 确认依赖 / 端口 / 数据齐全，再确认 `http://127.0.0.1:8000/api/health` 返回 `{"status":"ok"}`；
2. 打开首页确认默认进入**智能工作台**（不是数据看板）：AI 洞察 Hero、4 张 Stats Card、推荐机会与「即将截止」都有数据；
3. 关闭自动更新与通知弹窗。

### 镜头 7｜日期为什么不会错 + 新闻稿文体闸门（3:00–3:30）★差异化

## 不要做的事

1. **不要用假数据演示未实现的功能**。组委会总决赛会复现材料，视频里出现但代码里没有的功能会被直接质疑。
2. **不要开倍速**。评委看不懂操作过程，等于没演示。
3. **不要念 PPT 上的文字**。视频讲「怎么用」，PPT 讲「为什么这么做」。
